# 微信视觉模板

本目录存放本地截图裁剪得到的 PNG 模板，不提交包含账号、手机号、聊天内容或任务数据的完整截图。

| 文件名 | 采集区域 | 用途 |
| --- | --- | --- |
| `wechat_home.png` | 微信主页稳定且不含账号信息的固定 UI 区域 | 确认微信主页 |
| `search_box.png` | 下拉小程序面板中的搜索框图标或边框 | 定位搜索输入框 |
| `meituan_icon.png` | 下拉面板中美团小程序图标 | 优先直接进入美团 |
| `meituan_result.png` | 搜索“美团”后的美团结果图标/标题区域 | 点击搜索结果 |

模板建议裁剪为 40 至 160 像素的稳定局部区域，避免姓名、头像、时间和动态推荐内容。当前匹配阈值为 `0.82`，并在点击美团图标或搜索结果前要求连续两帧位置稳定。
