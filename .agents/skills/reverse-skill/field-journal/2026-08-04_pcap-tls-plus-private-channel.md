# PCAP：TLS 解密后仍有私有应用层通道

> 日期：2026-08-04  
> 场景：本地授权 PCAP，已脱敏

## 可复用结论

SSL key log 成功并不代表业务字段一定可见。移动应用可能同时使用：

1. 标准 TLS/HTTP2 承载静态资源、遥测和 WebSocket；
2. 端口 80/8080 上的私有 TCP 帧，结构化前缀后接高熵载荷；
3. TLS 内再做一次应用层加密。

## Evidence 摘要

- E-001：先用 SHA-256 和 `capinfos` 保全原始样本。
- E-003：加载 key log 后比较前后协议层级，确认 TLS 是否实际解密。
- E-004：目标字段未命中，同时存在大体量非 HTTP 高熵流，不能把“未匹配”解释为“数据不存在”。

## 推荐路径

PCAP triage → TLS key log → HTTP/2 body → 目标字段搜索 → 私有流聚类 → 应用运行时 Hook/协议还原。
